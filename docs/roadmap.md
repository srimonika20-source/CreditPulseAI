# Roadmap

| Phase | Milestone | Key deliverables |
|---|---|---|
| 1 | Foundation | Folder structure, settings, theme, landing page, placeholder modules, starter tests |
| 2 | Data | Reproducible synthetic NBFC generator (≥20k loans, 36 months), validation, SQLite load |
| 3 | Portfolio Metrics | Metrics engine, Executive Overview dashboard |
| 4 | Risk Analytics | Delinquency, vintage and roll-rate engines and pages |
| 5 | Detect & Diagnose | Anomaly detection, contribution analysis |
| 6 | Prescribe | Evidence-linked recommendation engine, risk alerts |
| 7 | Analyst & Track | AI Credit Analyst, Action Tracker with persistence |
| 8 | Release | Test coverage, docs, UI polish, Streamlit Community Cloud deployment |
